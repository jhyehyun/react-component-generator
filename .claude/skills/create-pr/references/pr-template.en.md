# PR Template (English)

Rules:
- Replace every `<...>` placeholder with real content. Leave none.
- Do not delete sections that do not apply; write "None".
- Summarize the meaning of the change; do not paste the commit log.

Title format: `<type>: <English summary>` (feat / fix / refactor / chore, within 70 characters, no trailing period)

```markdown
## Summary

<1-3 sentences on what this PR changes and why>

## Changes

- <change 1>
- <change 2>

## Motivation

<Background, the problem being solved, related issues (e.g. Closes #12)>

## Testing

- [ ] <test command that was run, e.g. the project's test script>
- [ ] <lint / build, if applicable>
- <manual verification, if any>

## Notes for reviewers

<Areas to focus on, known limitations, follow-ups. "None" if nothing>
```
